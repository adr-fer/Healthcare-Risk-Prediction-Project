# Healthcare Risk Prediction Project

## Project Description

This end-to-end healthcare analytics and machine learning project was developed using Amazon Web Services. It demonstrates data cleaning, filtering, exploratory data analysis, KPI analysis, feature engineering, and predictive modeling using healthcare data.

AWS Glue and PySpark are used to clean and prepare the datasets, Amazon Athena and SQL are used to calculate KPIs and analyze relationships between variables, and Amazon SageMaker and Python are used to create predictive features, train machine learning models, and evaluate results.

The primary objective is to identify patient encounters at risk of generating unusually high treatment costs and determine which healthcare variables can be used to predict future outcomes.
